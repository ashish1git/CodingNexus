Single command:

    node scripts/dsa-codes.mjs add

  That's it. No arguments needed. It generates a random code like CNX-DSA-A3F72B with unlimited uses. Give that code to the
  student.

  If you want a limited-use code (e.g., 30 students max):

    node scripts/dsa-codes.mjs add "batch-A" 30

  Where "batch-A" is just a label for your reference, and 30 is the max uses. Give the generated code to students — once 30
  people use it, it stops working.
